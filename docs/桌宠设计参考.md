# 成本台 · CostDesk — 桌宠（桌面宠物）设计文稿 v2

> 交付对象：WorkBuddy 执行端
> 用途：工作台单文件 HTML 内嵌桌宠系统的重做依据
> 配套图片：本目录下 cat.png / shiba.png / rabbit.png / redpanda.png / cat-evolution.png
> 重要：效果图仅作**造型与质感参考**，最终必须用**内联 SVG** 重绘（单文件、离线可用、不依赖外部图片），禁止直接外链图片。

---

## 1. 设计目标

- 桌宠是工作台的"情绪价值小巧思"：随报价行为成长，给采购岗位一种被陪伴、被鼓励的感觉。
- 本次从"幻想生物系"整体更换为**动物系**：生动、可爱、有亲和力。
- 调性：3D 萌系 Q 版（圆润、短胖、大眼、柔软绒毛感），在深色专业工作台上要醒目、耐看、精致，不能是廉价占位图形。
- 与产品定位一致：可爱但不能喧宾夺主，默认收起在小角落，可拖动。

## 3. 进化机制（本次核心变更）

- **只有体型大小变化**：幼体（极迷你，约手掌大小）→ 成体（标准桌宠大小）→ 最终体（明显更大、更圆润饱满）。
- 长相、配色、表情、姿势、道具**完全一致**，只有尺寸/圆润度递增。
- **严禁**：跨物种、判若两宠的大跨度变化、只换配色冒充进化。
- **扣除闪耀形态**：不要闪耀 / 异色 / 金色光环档，形态上限 = 最终体。
- 参考图：`pet-design/cat-evolution.png`（从左到右 = 幼 / 成 / 终）。

## 4. 进化触发（保留既有逻辑）

- 以报价行为积累经验值：完成报价、批量报价、分享报价等计入经验。
- 经验达阈值 → 体型升档：幼体（0）→ 成体（N1）→ 最终体（N2）。阈值沿用现有设定或简化为三档即可。
- 进化时给一个简短动画（放大 + 微光）与气泡文案（如"长大啦！"），不打扰核算操作。

## 5. 交互与行为（这些都不能删）

- 不跟手（不随鼠标移动）。
- 可拖动放置，拖动位置记忆（localStorage）。
- 双击收起 / 双击唤出。
- 情绪化表现：
  - 喂糖彩蛋（点击/长按喂食，出现开心反应）；
  - 连续报价后兴奋动画（跳跃/转圈/冒星）；
  - 闲置打盹（一段时间无操作自动瞌睡）；
  - 3–5 分钟自动巡检自检 + 气泡提示（如"价格库有 2 条快过期"——可联动预警数据，做不了则保持通用鼓励语）。
- 支持多只可选：保留"切换动物"入口（本次完整实现橘猫，柴犬/白兔/小熊猫可先做形象占位或后续补齐）。

## 6. SVG 实现规格（橘猫示例，其余同理）

- 整体：内联 SVG，viewBox 建议 0 0 200 200，居中绘制。
- 特征锚点（必须可辨认，照效果图重绘）：
  - 圆润短胖身体，橘白渐变毛色（背部橘色 #F59E5B 系、肚皮米白）；
  - 圆脸 + 琥珀色水润大圆眼（高光点）、粉色小鼻、左右各三根细胡须；
  - 一对三角尖耳（内耳粉嫩）、脸颊淡橘腮红；
  - 尾巴卷成小勾；一只前爪抬起（招手姿态）；
  - 脚下浅色椭圆投影。
- 三档体型：用同一套 SVG 图形按比例缩放（幼 ≈ 55%、成 ≈ 100%、终 ≈ 150%）+ 最终体适度加圆润；不能改变五官比例关系。
- 状态表情：开心（眯眼笑）/ 打盹（闭眼 z z z）/ 兴奋（眼睛发光 + 星点）等通过切换眼/嘴/装饰元素实现。
- 动画：CSS animation 即可（呼吸起伏、眨眼、跳跃），保持轻量，不阻塞核算台性能。

## 7. 与工作台的集成行为

- 桌宠固定在核算台右下角或可拖到任意位置（记忆）。
- 报价完成/批量报价时给即时正向反馈（兴奋动画 + 气泡）。
- 数据联动（可选，做不了不强求）：价格库过期预警条数可让桌宠气泡播报。
- 不遮挡核算按钮与一键报价入口；收起状态下仅露出小图标。

## 8. 验收清单（交付前逐项实测）

1. 桌宠为动物系橘猫 Q 版，观感精致可爱（对照 cat.png）。
2. 无闪耀形态；只有幼/成/终三档，且仅体型变化、五官一致（对照 cat-evolution.png）。
3. 不跟手；可拖动且位置记忆；双击收起/唤出。
4. 喂糖有反应；连续报价会兴奋；闲置打盹；自动自检气泡。
5. 报价/经验达到阈值后体型变大，有简短进化动画。
6. 页面打开无 console 报错；桌宠动画不影响核算台流畅度。
