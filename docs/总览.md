### B 五条实测体验优化
1. **必填校验显眼化**：错误文案→缺失字段映射（含剂型自定义必填字段正则解析）；红框 + 红点（`.req-dot` 脉冲）+ 顶部 toast「还差：剂型 / 软糖类型」（可点击）+ 右侧错误条目可点击；点击即平滑定位并 `focus()`。
2. **识别弹窗「✨AI 识别」快捷入口**：5 个弹窗接入（图片/文字/OCR降级/文本配方/报价单）；已配置默认优先 AI（图→视觉模型、文→文本模型），失败自动回退本地；未配置置灰 + 提示 + 自动跳转设置页；开关记忆于 `meta.ui.aiPref`。
3. **「最近使用」真打通（根因修复）**：根因=`recent.quotes` 只在当次存档时写入，老档/升级用户该列表恒空 + 面板默认折叠 + 存档后不刷新。修复=`store.backfillRecent()` 加载回填 + 存档后 `refreshRecentOpen()` 立即刷新并展开 + 报价条目升级为「方案名 + 时间 + 单份成本」整行可点载入复用 + 事件委托改为绑定一次。
4. **设置页「重置宠物养成」**：确认弹窗 → `resetGrowth()` 经验/体型/昵称归零回幼体，保留位置记忆与已选动物；连带修复 `syncFromQuotes()` 每次启动按历史 amount 顶回经验、导致重置失效的根因（改为一次性迁移）。
5. **商务参数小摘要精简**：标题旁「MOQ·含税口径·税率·利润率」整行移除（右侧面板已实时完整呈现）。
