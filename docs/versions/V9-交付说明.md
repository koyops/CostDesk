## 一、本轮核心：把「伪进化」重做成「真进化」

**背景缺陷**：V8 的三阶形态是「同一胶囊骨架只换配色/微调大小」，视觉上不构成进化；图鉴里三格并排像同一只宠的三个滤镜版本，缺乏养成成就感。

**本轮目标**：参考宝可梦真实进化逻辑（小火龙→火恐龙→喷火龙），给每只精灵的每一阶做**结构级重绘**，保证相邻两阶在 ≥3 个维度同时质变：

| 维度 | 含义 | 本轮的实现 |
|---|---|---|
| 体型 | 终体≈幼体 2–3 倍 | 幼体只占视框约 7 成高、圆团小只；终体逼近满框、翼展横贯左右（图元数阶梯 24→31→41 等，见第三节） |
| 姿态结构 | 四足趴地 → 两足直立 → 展翼飞行 | 小焰龙：趴地圆团 → 直立行走 → 展翼昂首；小天龙：卷曲 → 双 S 拉长浮空 → Q 版裂空座横空 |
| 特征配件 | 新增角/翼/脊刺/能量核心/色块 | 犄角芽→大弯角+额冠刺、背部鳍膜→大翼膜、V 电冠+胸甲电纹、裂空座式冠角+腹部黄 V 纹、异色肚皮、颊部色块 |
| 配色深化 | 属性色加深 + 对比点缀 | 火 #FF8A3C→#F97316→#D9480F 逐阶加深 + 终体蓝焰反转；电 #FFE14D→#FACC15→#FBBF24 + 电蓝 #3B82F6 胸甲；空 #57D2AE→#2FB98E→#12A06C 青绿渐深 + 腹部黄线变亮 |
| 气质 | 呆萌 → 活泼 → 霸气 | 面部参数化（`faceSvg` 的 `fierce` 凶眉/眼距/嘴型）+ 眼周配件随阶变化：幼体大眼天真，终体锐利威压 |

**结果**：12 个形态的 SVG 字符串两两互不相同（测试断言），相邻阶之间不再共享任何一处完整矢量路径——「判若两宠」。

## 四、量化证据（自动化断言背后的数字）

- **图元数阶梯**（circle/ellipse/rect/path/line 计数，从真实产物 SVG 统计）：火 **24 → 31 → 41**；电 **28 → 31 → 40**；空 **28 → 30 → 44**——每阶复杂度单调上升，终体接近幼体两倍。
- **闪耀 = 同骨架**：三系闪耀图元数与终体完全一致（41/40/44）——几何不动、调色板整体替换，佐证「异色稀有版」而非另画一只。
- **结构飞跃断言**（test-v8.js / 演示页内检）：火/空 幼体无 `an-wing`、进化体与终体含；电系全程无翼但有 `an-ear` 耳动组；火/空幼体无耳。
- **配色深化断言**：火 #FF8A3C→#F97316→#D9480F、电 #FFE14D / 终体含电蓝 #3B82F6、空 #57D2AE→#12A06C 均在产物 SVG 中逐一出现。
- **闪耀调色板唯一性断言**：香槟金 #F6CF5B / 白金 #F4F8FB / 象牙金 #F3EED8 只在 `svgSpecies(id,3,true)` 输出中出现，普通三阶输出一律不含。
- **12 形态唯一性断言**：3 系 × 4 形态共 12 组 SVG 字符串两两不同；12 个形态名全局唯一。
- **40px 可缩放**：全部 SVG 为 `viewBox="0 0 92 104"` 矢量、零外链字体/图片；线宽不小于 0.8、主体轮廓 1.2–1.5，缩到 30px（面板进化链 `pp-chain`）仍可辨认轮廓与属性色。
