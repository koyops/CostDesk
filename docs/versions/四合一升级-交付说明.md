## 一、P0-1 图片识别配方：支持拖拽上传

**实现方式**（`src/ui-recognize.js`）：

- 图片识别入口由「选文件按钮」升级为**整体拖放面板** `#ocrDrop`：`dragover / dragenter` 时切换 `.drag` 高亮类（品牌蓝描边 + 图标上浮），提示文案实时变为 **「松开上传，开始识别…」**；`dragleave` 恢复默认提示；`drop` 立即进入识别流程。
- **文件校验** `checkImageFile(f)`（纯函数，可单测）：
  - 类型：扩展名 `\.(jpe?g|png|webp|bmp)$` 或 MIME `image/(jpeg|png|webp|bmp)`；
  - 大小：`> 20MB` 拒绝；
  - 不合规 → toast「仅支持图片文件（jpg / png / webp / bmp），已忽略」/「图片超过 20MB 上限，请压缩后重试」，**面板保持打开不崩溃**。
- **多图只取第一张**：`drop` 时 `files.length > 1` → toast「仅支持单张图片，已取第一张进行识别」，仅处理 `files[0]`。
- **保留点击选择入口**：点击拖放区 → 隐藏 file input（`accept="image/*"`，同一套校验回调）；`keydown Enter/Space` 等价触发（可访问性）。
- **识别流程不变**：校验通过 → 关闭面板 → `runOcr(f)` → 识别中（进度）→ 识别文本 → 识别确认面板 → 确认导入原料清单。OCR 失败仍降级「手动粘贴文字」；页脚常驻「手动粘贴文字」降级按钮。
- 导出 `openImgPickPanel / checkImageFile`，冒烟测试可直达验证。

## 三、P1-3 报价小宠「小胶囊精灵」

**实现方式**（新增 `src/ui-pet.js`，纯内联 SVG + CSS，零外链）：

- **独立持久化**：localStorage key `WB_PET_V1`，结构 `{count, lv, mini, lastLvShown}`；首启以「报价存档」条数兜底计算等级（老用户直接获得对应形态），之后仅由报价成功次数驱动。
- **四级成长表**：

| 等级 | 次数 | 形态 | 动效 |
|---|---|---|---|
| Lv1 幼体 | 0–9 | 灰色豆丁 | 原地轻摇（petIdle） |
| Lv2 成长 | 10–29 | 绿色 + 头顶嫩芽 | 摇摆 + 芽 |
| Lv3 成熟 | 30–79 | 品牌蓝 + 双翼 + 淡蓝微光 | 摇摆 + 微光呼吸（glowPulse） |
| Lv4 完全体 | ≥80 | 金环 + 皇冠 + 光点粒子 | **浮空**（petFloat）+ 4 颗金色光点 + 星芒 |

- **计数挂钩**：`ui-calc.js runQuote()` 成功路径尾部调用 `global.WB.pet.onQuote()` —— 与「一键报价」成功严格绑定（校验失败不计数）。
- **报价成功反馈**：跳跃庆祝（petJump）+ 爱心/星星粒子（`.pet-spark`，BMP 符号字形 ♥★✦❋✧，无 emoji）+ 等级气泡「LvX · 还差 N 次进化」（满级「已是完全体」）。
- **升级全屏轻提示**：跨档瞬间弹出「小胶囊进化啦！LvX · 形态名」+ 新形态 SVG 徽章，每级仅提示一次（`lastLvShown` 去重）。
- **交互**：单击宠物 → 信息面板（等级 / 累计次数 / 进化方向 / 距下级进度条 / 最小化 / 收起）；双击 → 最小化为小圆点（`.mini`，可点回还原）；点面板外任意处自动收起。
- **初始化**：`app.js init()` 末尾 `global.WB.pet.init()`；`build.js JS_ORDER` 插入 `ui-pet.js`（位于 `ui-quotes.js` 与 `app.js` 之间）。

## 四、P1-4 整体 UI：专业客户端质感

**实现方式**（`src/index.html` 骨架重构 + `styles.css` V5 覆盖层，不推倒 V4 设计系统）：

- **左侧固定导航**：`aside.sidebar`（196px，sticky 100vh）——品牌区 + 7 个 `nav-item`（内联 SVG 图标 + 文字：核算台/原料价格库/包材库/配方库/报价存档/预警看板/设置）+ 底部状态区（同步指示/保存状态）。选中项左侧 **3px 品牌蓝竖条**（`.nav-item.active::before`）。
- **顶部操作栏**：主列 `header.topbar`（sticky 48px）——面包屑 + 全局搜索 + 快捷键提示；核算台工具条 `calc-topbar` 紧随吸顶。
- **分区卡片**：核算台左主区「产品参数 / 商务参数 / 原料清单 / 包材区」+ 右侧结果栏；卡片 14px/16px 内边距、圆角 12px、柔和阴影分层。
- **设计令牌**：主色 `#2563EB`、背景 `#F5F7FA`、卡片 `#FFF`、分隔线 `#E2E8F0`、控件 34–36px / 圆角 8px / 聚焦蓝描边 `box-shadow 0 0 0 3px rgba(37,99,235,.12)`、8px 间距基数、150–200ms 动效、8px 细滚动条。
- **表格化信息密度**：全部清单类内容改为紧凑表格（见 P0-2），禁止「一卡一高块」。
- **折叠交互**：商务参数默认一行摘要（v4 已有），原料/包材卡可折叠为一行（新增）。
