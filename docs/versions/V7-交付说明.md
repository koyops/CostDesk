## 一、本轮三项升级

### ① 核算台「真·实时联动」（P0）

**背景缺陷**：此前输入事件零散绑定，`f-weight / f-count / f-net / f-box` 及部分商务参数漏绑，存在「改了不刷新」；重算逻辑散落多处，无单一入口。

**修复**（`src/ui-calc.js`）：
- **单一入口 `recalcAndRender()`**：任何变化（原料行配比/单价/临时价、包材行、产品参数、商务成本、识别带入、价格库联动）→ `scheduleAuto`（300ms 防抖）→ 统一「读 DOM → computeQuote + computeTiers → 渲染结果 → 高亮变化项 → 标红无价行 → 刷新顶部摘要 → 状态『✓ 实时核算』」。
- **document 级事件委托 + `data-trigger="calc"` 打标**（静态控件 20+ 处，含此前漏绑的克重/每瓶数量/净含量/装箱），一次性守卫防重复 init 重复监听；行级控件（配比/临时价/每瓶用量）渲染时直绑同入口。
- **容错不中断**：配比合计 ≠100% 只出黄条提示；原料无价仅标红行 + 「无价」角标、按 ¥0 参与估算，绝不阻断结果渲染；清单为空时保留空状态引导文案，不刷出满屏 ¥0。
- **关键数字闪烁** `flashChanged(prevNum)`：仅对数值发生变化的项做 500ms 高亮（首算全亮），改哪亮哪。
- 兼容旧调用：`autoCalc` 与 `recalcAndRender` 同引用，识别导入/价格库联动/快照回滚等既有调用不受影响。

### ② 报价小宠「胶囊小精灵」V7 — 宝可梦式养成重做（P0）

**重做内容**（`src/ui-pet.js` 28 KB 全量重写 + `styles.css` 宠物样式覆盖层）：
- **四级进化形态**（阈值 0/10/30/80 与旧版一致，老用户等级顺滑衔接）：Lv1 **豆丁**（灰白呆萌）→ Lv2 **嫩芽**（草绿冒芽）→ Lv3 **灵能**（品牌蓝 + 光翼 + 微浮 + 淡蓝辉光）→ Lv4 **黄金体**（金环 + 皇冠 + 漂浮光点）。
- **生物化造型**：圆润胶囊身 + 大眼（可眨眼）+ 腮红 + 小触角 + 短尾；纯内联 SVG + CSS keyframes，零外链 / Lottie / emoji。
- **交互**：单击开合信息面板（进度条/连报数/喂糖数）、双击最小化/还原、**拖动换位并记住位置**（Pointer 优先）、命名（默认「小成」）、喂糖果彩蛋（10 条台词）、连续报价 ≥3 兴奋特效、30 分钟未互动打盹 Zzz、升级进化动画（抖动 → 白闪 → 新形态 + 全屏轻提示，每级仅提示一次）。
- **报价挂钩**：`runQuote()` 成功后计数 +1 → 跳跃庆祝 + ♥★✦❋✧ 粒子（BMP 字形，不破坏「无 emoji」红线）+ 等级气泡。

**本轮顺带修复的 3 个真实缺陷**（均有复现路径）：
1. **气泡永久丢失**：`render()` 以 `root.innerHTML` 整体重建 `#petRoot`，而模板里没有 `#petBubble` → `bubble()` 静默失效，气泡元素从 DOM 消失。修复：render 模板补回 `<div class="pet-bubble" id="petBubble">`。
2. **面板永远打不开**：模板给 `.pet-panel` 内联 `style="display:none"`，内联样式压过 `.pet-body.panel-open .pet-panel{display:block}` → 点小宠永远不会展开信息面板。修复：移除内联样式，交给 CSS 类控制。
3. **「喂糖果」按钮带 🍬 emoji**：违反产品红线「无 emoji 功能图标」（冒烟断言直接失败）。修复：换为同尺寸内联 SVG 糖果线性图标。

### ③ 品牌升级：CostDesk + 图标（P0）

- 全站产品名统一 **CostDesk**，副标「成本台 · 采购快速报价」；HTML title、侧栏品牌区、**面包屑前缀**、LOGO title 全部统一（`index.html`）。
- **新品牌图标**：40px 深色圆角方底 + 金属键盘/账本线条 + 品牌蓝圆点（成本台意象），纯内联 SVG（渐变 defs），无 img / 无系统图标 / 无 emoji。
- **顺带修复**：面包屑品牌前缀此前被 `updateCrumb()` 运行时改写丢弃（静态模板有、切一次视图就没了）→ 现在每次重写面包屑都保留 `<b class="cd">CostDesk</b> · ` 前缀（`src/app.js`）。
- CSV 导出抬头/文件名保留功能性「报价核算」字样，不做品牌化（与 V6 口径一致）。
