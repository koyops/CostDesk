# 保健品OEM内部报价工作台 v3 — 更新说明

> 交付物：`CostDesk.html`（单文件，双击即可用，无后端、纯前端）
> 本次为 **v2 → v3 增量升级**：不推倒重来、不回退任何已有功能；旧数据（v2 备份 JSON）可直接导入，自动补齐新字段。

## 一、本次改动点

### 1. 识别配方：回归并升级为「先确认后入库」安全流程

- **三大识别入口全部回归**，位于核算台空状态四入口卡片与操作栏：
  - 📷 **图片识别**（OCR）：支持拖拽/点击上传图片
  - 📋 **粘贴文字**：直接粘贴配料表文本，**无后端也能用**（OCR 降级方案）
  - 📄 **文档上传**：TXT / Word(docx) / Excel(xlsx) 纯前端提取文本（无需上传服务器）
- **解析规则增强**：中英文单位（mg/g/μg/IU/%/kg/粒/片）、「每粒含/每100g含」前缀、逗号/顿号/分号拆分、百分比配比、括号注释剥离、辅料行自动识别为 `excipient`、供应商行/净含量行提取。
- **关键流程「先确认后入库」**：识别结果先进「识别确认」弹窗 —— 可逐行修改名称/用量/单位/配比/成分类型、删除行、补行、一键匹配原料库、未匹配行可「建草稿」；**点「确认导入」后才会写入原料清单**，未确认不污染数据。
- **体验**：扫描动画加载态（1~3 秒）、重新识别、**最近 10 次识别历史**可回看复用。
- **OCR 说明**：浏览器无法本地识图，未配置 OCR 服务时图片入口会引导使用「粘贴文字」（等价降级，功能不受影响）。

### 2. 核算台重构：一屏完成报价（三段式）

- **顶部 sticky 操作栏**：方案摘要 | **⚡一键报价（最大权重 CTA）** | 存档 | PDF | Excel | 对比，始终可见。
- **左主区**：产品参数 + 商务参数两列栅格；**商务参数可折叠为一行摘要**（默认折叠，展开不占首屏）；原料清单默认展开；**包材区紧邻原料下方默认展开**，包材用**侧滑抽屉**搜索多选添加。
- **右侧 sticky 面板**：实时核算结果 + 成本构成迷你环形饼图（悬浮显示数值），滚屏时始终可见。
- 首屏 1280×800 即可看到添加原料、添加包材、一键报价全部核心入口。

### 3. 全局效率（P1-1）

- **Ctrl+K 全局搜索**：检索原料/包材/配方/报价/识别历史，↑↓ 选择、Enter 跳转、Esc 关闭。
- **面包屑**：核算台 > 报价详情，随视图自动联动。
- **最近使用**：最近 5 个报价/配方/剂型一键复用。

### 4. 人性化交互（P1-2）

- 空状态**四入口卡片**：📷 识别配方 / 📋 粘贴文字 / 添加原料 / 选配方带入。
- 必填校验：字段级实时提示 + 校验失败高亮 + **自动滚动定位到第一个错误**。
- **版本快照**：每次一键报价自动记录参数快照（最多 20 条），可回滚、可对比。
- 专业术语 tooltip：MOQ / 计价口径 / 工艺溢价等。
- 数值右对齐 + 千分位格式化。

### 5. 数据与洞察（P1-3）

- **成本构成环形饼图**：悬浮显示各成本项数值。
- **原料价格趋势红线**：供应商历史价格波动可视化，过期报价自动预警。
- **报价转化看板增强**：按月趋势（近 6 个月双柱图）、按剂型转化、按客户转化。

## 二、识别配方用法（3 步）

1. **入口**：核算台顶部「📷 识别配方」按钮，或空状态卡片选择任一入口：
   - 粘贴文字：`Ctrl+V` 直接粘贴配料表 → 「解析」
   - 上传文档：选择 txt/docx/xlsx → 自动提取
   - 上传图片：选择/拖拽图片 → 若未配置 OCR 服务会提示粘贴文字
2. **确认**：在「识别确认」弹窗中核对每行成分 —— 名称、用量、单位、配比、成分类型均可改；未匹配原料库的行点「一键匹配」或「建草稿」；可删行、补行。
3. **入库**：点「✓ 确认导入原料清单」→ 原料进入核算台原料清单 → 填好方案名/剂型/克重/数量 → **⚡一键报价**。

> 例：粘贴 `每粒含：维生素C 200mg，牛磺酸 100mg` → 解析出 2 行（名称/用量/单位自动拆分，配比自动换算）→ 确认后入库 → 直接报价。

## 四、文件说明

```
oem-v3/
├── CostDesk.html   ← 交付物（单文件应用）
├── 更新说明.md                    ← 本说明
└── src/                           ← 模块化源码（构建产物 = 合并单文件）
    ├── build.js                   ← 构建脚本（合并 → 单 HTML）
    ├── index.html / styles.css    ← 结构 / 样式
    ├── parse.js / calc.js         ← 纯函数：配方解析 / 成本核算（可单测）
    ├── store.js                   ← 数据层（localStorage + 备份导入导出）
    ├── ui-common.js / ui-recognize.js / ui-calc.js
    ├── ui-libs.js / ui-quotes.js  ← 各模块 UI
    ├── app.js                     ← 入口（视图切换 / Ctrl+K / 面包屑）
    └── test-parse.js / test-calc.js / test-smoke.js ← 测试
```

**运行**：直接双击 `CostDesk.html` 在浏览器打开即可（数据存浏览器本地）。重建：`node src/build.js`；测试：`node src/test-parse.js && node src/test-calc.js`，冒烟测试需 `NODE_PATH` 指向含 jsdom 的 node_modules。
