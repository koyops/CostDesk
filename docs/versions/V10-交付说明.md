## 一、A. 宠物系统重做（对照 `pet-design.md` 验收清单逐项达成）

**形象**：由"幻想生物系（小胶囊/三系精灵）"整体更换为**动物系主推「招财橘猫」**——圆润短胖身体 + 橘白渐变（背部 #F59E5B 系 / 肚皮米白）、琥珀水润大眼（高光点）、粉色小鼻、左右各三根细胡须、三角尖耳内粉、脸颊淡橘腮红、卷勾小尾、一只前爪抬起招手（"接单赚钱"招财寓意）、脚下浅色投影；毛绒质感用 `feGaussianBlur` 柔化 + 渐变实现。全部**内联 SVG（viewBox 0 0 200 200）绘制，零外部图片**，深色桌面醒目耐看。

**进化机制（本次核心变更）**：
- **只有体型大小变化**：同一只猫由外层 `<g transform="scale(s)">` 收纳同一套矢量图形，幼体 s=0.55（极迷你）→ 成体 s=1.0（标准桌宠）→ 最终体 s=1.45（更大更圆润）。
- 长相 / 配色 / 表情 / 姿势 / 道具**完全一致**，杜绝跨物种、判若两宠、只换色。
- **已扣除闪耀形态**：无闪耀/异色/金色光环档，形态上限 = 最终体「大橘」；经验阈值简化为三档 **0 / 10 / 30**（`calcLevel(80)` 封顶 Lv3），DOM 形态类 `st1/st2/st3`。

**保留的既有交互（一条未删）**：不跟手（无鼠标跟随实现残留）；可拖动放置 + 位置记忆（localStorage `WB_PET_V2`，含 pos）；双击收起/唤出；长按/点按喂糖彩蛋（开心反应）；连续 3 次报价兴奋（冒星 5s）；闲置 4 分钟打盹（闭眼 + Zzz）；每 60s 轮询的 3–5 分钟自动巡检（联动价格库过期预警 → 气泡播报"价格库有 N 条报价已过期"）；随报价行为升体型（每次一键报价 +1 经验，跨阈值触发"放大 + 微光 + 长大啦！"进化动画与弹层）；面板展示三体型进度链（`幼猫/成猫/大橘` 三格，已完成格点亮）；支持多只扩展位（`SPECIES` 数组 + `unlockSpecies` 兼容壳保留，本次完整实现橘猫一套）。

## 四、顺带修复的真实 Bug（回归中发现并修掉）

1. **桌宠自动巡检崩溃**：`ui-pet.js` 的 `selfCheck()` 引用未声明的 `C`（calc），一旦价格库存在任意供应商数据，4 分钟巡检即抛 `ReferenceError`——已补 `var C = global.WB.calc`（价格库过期预警联动正是走这里）。
2. **闲置打盹不闭眼**：`setMood('sleep')` 只加 `mood-sleep` 类，CSS 睡眠样式挂在 `.pet-body.sleep` 上导致永远不生效——已改为 toggle `sleep` 类（闭眼 + Zzz 真实出现）。
3. **配比警告不即时**：改配比后清单不重绘导致"合计≠100%"警示条不出现——新增轻量 `syncRatioWarn()`（不打断输入焦点），每次实时核算同步警示条数字与显隐。
