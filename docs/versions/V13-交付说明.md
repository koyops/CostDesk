## 一、识别能力大幅增强（A）

### 1. 本地解析强化（默认离线可用）
- **OCR 纠错词典**（`parse.js`，50+ 条）：常见保健品原料的缩写/英文/近形错字自动映射回标准名
  — `维c/VC → 维生素C`、`coq10 → 辅酶Q10`、`collagen → 胶原蛋白肽`、`gaba → γ氨基丁酸`、`虾青素 → 雨生红球藻` 等；命中后行置信度提升至 ≥0.9。
- **乱码检测**：按 n1 截图真实乱码样本（`BRETRITEITH(RAEMeon` 等）校准特征——元音占比 <0.45 / 4 连辅音 / 词典外长英文串 → 置信度压至 ≤0.35~0.6 并标「疑似乱码待确认 / 英文待确认」，**不静默当作正确值**。
- **多格式解析**：名称+含量%、名称 用量 单位、制表符、多空格、括号注释（别称入备注）、中英混排、范围值、每粒含前缀——均已由 test-v13 逐条覆盖。

### 2. AI 识别增强（主推，可选）
- **设置 → AI 识别增强**：`接口地址 Endpoint / API Key / 文本模型 / 视觉模型` 四项配置（视觉模型留空自动沿用文本模型）。
- **图片识别**：已配置 AI 时，图片转 base64 直送**视觉模型**（OpenAI Chat Completions 视觉消息格式），要求返回结构化 JSON（名称/用量/单位/含量%/类型/价格/置信/备注）回填确认表——对清晰配料表，名称正确率远高于本地 OCR。
- **文本/报价单**：送文本模型结构化（V12 通道保留）。
- **双模式与回退**：AI 失败/无网/未配置 → 自动回退本地（Tesseract OCR + 规则解析），进度条与提示明确标注**「本地模式」**。
- AI 结果只进确认表预览，仍可人工编辑、建草稿、一键匹配、确认导入；**不直接覆盖任何数据**。

### 3. 识别确认表质量提示
- 行首**来源徽标**（`AI` 绿 / `本地` 灰）+ 弹窗顶部模式标签（AI 模式 / 本地模式）；
- 低置信/乱码行**整行红标 + 「待确认」角标**；
- 每行新增 **「重新识别这一行」** 按钮（↻）：有原文且已配置 AI 走 AI 文本通道，否则本地规则重解析，自动回匹配原料库。

## 四、桌宠系统深度升级（D）

### 案例调研结论（已提炼落地）
| 案例 | 采纳点 |
|---|---|
| Shimeji（桌面宠物鼻祖） | 动作分层（常驻 idle 循环 + 事件触发一次性动作）、场景感知（对用户操作做反应）、不干扰主流程 |

### 1. 3D 建模感
在 V12 渐变基础上新增：身体**顶部受光带 + 底部体积反光**（模糊高光/阴影双椭圆）、头部**左上主高光**柔光斑、**绒毛边缘**（细毛描边）、鼻头高光点——立体光影、体积层次到位，无扁平色块。

### 2. 动作库（≥5 种，自然切换）
呼吸起伏（常驻）、眨眼（3.8s 循环）、**摇尾**（卷尾挂载 an-tail 摇摆）、招手（2.2s 循环）、开心眯眼笑+跳跃（报价成功 celebrate）、兴奋冒星+摇摆、打盹+zzz、自检抬头+问号气泡、喂糖**咀嚼**、点击**撒欢**、**委屈抱怨**（新增 upset 态：下撇嘴+汗滴+摇头，核算异常时 45s 节流触发）、进化动画（放大+光效）。一次性动作由 `WB.pet.act(name)` 驱动，播完自动移除。

### 3. 养成保留（零回退）
报价经验 → 幼猫/成猫/大橘三体型；经验/体型/位置/昵称 localStorage（`WB_PET_V2`）持久化，刷新/切板块/重启不丢；拖动/双击 mini/长按喂糖全部保留。

### 4. 对话 AI / Agent（桌宠 = AI 报价助手）
点击桌宠弹出面板，底部即对话窗，**本地 Agent 默认离线可用**，支持六类查询：
- `维生素C 什么价` → 原料库最优价+有效期
- `哪家供应商最便宜` → 比价排序（低→高 Top3）
- `当前配方报价多少` → 实时概算（单份/不含税/含税/MOQ）
- `胶囊的默认参数` → 剂型默认克重/粒数/净含量/损耗
- `我的报价历史` → 最近 5 条存档
- `快捷键` → 快捷操作说明

可选**在线大模型增强**（沿用设置页 AI 配置）：问句+脱敏本地上下文（原料名+最优价/当前方案概算）送文本模型，未配置/无网/失败自动回退本地。AI **只读查询**、写操作不执行、不上传客户资料。

## 五、AI 如何配置（用户操作指引）
1. 「设置」→「AI 识别增强」→ 开启；
2. 填入 Endpoint（如 `https://api.openai.com/v1/chat/completions`，兼容 OpenAI Chat Completions 格式）、API Key；
3. 填**文本模型**（如 `gpt-4o-mini`）与**视觉模型**（如 `gpt-4o` / `qwen-vl-plus`，留空沿用文本模型）；
4. 保存后：图片识别自动走视觉模型、文本/报价单与桌宠对话走文本模型；未配置/断网/接口异常一律自动回退**本地模式**，功能不中断。API Key 仅保存在本机浏览器。
