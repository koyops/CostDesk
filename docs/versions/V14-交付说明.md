## 二、B · 五条实测体验优化

### B1 必填校验显眼化

- 新增「错误文案 → 缺失字段」映射表 `ERR_FIELD_MAP` + `resolveErrTarget()`，**剂型自定义必填字段**走正则解析「剂型字段「X」为必填」并精确定位到 `#dosageFields [data-cf=key]`。
- 校验失败时三件事同时发生：
  1. 缺失字段**红框**（沿用 `.field.invalid`）+ **红点**（新增 `.req-dot`，脉冲动画）
  2. 顶部 toast 汇总：`还差：剂型 / 软糖类型`（可点击）
  3. 右侧核算面板错误清单逐条可点击，带「定位 ›」提示
- 点击 toast 或错误条目 → `scrollIntoView` 平滑定位 + `focus()` 聚焦该字段。
- 兼容性：`U.toast` 第 4 参数 `onClick` 为**可选新增**，原三参调用行为完全不变。

### B2 识别弹窗「✨AI 识别」快捷入口

共接入 **5 个弹窗**：图片识别配方 / 文字识别配方 / 图片文字提取（手动粘贴）/ 文本配方识别 / 解析供应商报价单。

- **已配置**（设置里 开启 + Endpoint + Key 齐全）：开关默认高亮「优先 AI」，图片走视觉模型、文本/报价单走文本模型，失败或无返回**自动回退本地解析**（原链路未改）。
- **未配置**：开关置灰（`.ai-toggle.off`，不可点态），点击提示「请到 设置 → AI 识别 配置 Endpoint / Key」并**自动跳转设置页**（`#card-ai` 定位 + 聚焦 Endpoint 输入框）。
- 开关状态记忆在 `meta.ui.aiPref`，五个弹窗共用；可手动关闭强制走本地。
- 「文本配方」入口由原来的"直接弹文件选择器"改为**面板**（顶部含 AI 开关 + 选择/拖拽区），`#recFileInput` 仍预创建，入口链路与旧版一致。

### B3 「最近使用」真打通（**根因修复**）

**根因（实测复现，非猜测）**：
`recent.quotes` 只在"当次存档动作"时写入，老档 / 升级用户 / 已有存档的会话该列表**始终为空**；叠加面板默认折叠、存档后不刷新 —— 于是"存档页明明有记录，最近使用却显示暂无"。

**修复**：
1. `store.backfillRecent()`：加载时若报价最近列表为空而存档非空，按时间倒序**回填最近 5 条**，并清理已失效引用。
2. `saveQuote()` 成功后调用 `refreshRecentOpen()`：**立即刷新并自动展开**。
3. `applyRecent()`：初始化时还原用户展开态；从未设置过且有记录 → 默认展开。
4. 报价条目由纯文字 chip 升级为**整行条目**：**方案名 + 时间 + 单份成本**，点击直接 **载入复用**（`reuseQuote` 回到核算台）。
5. 事件委托改为在 `#recentBody` 上**绑定一次**，移除原先"全文档扫描 + setTimeout"的时序脆弱写法。

### B4 桌宠设置「重置养成」

- 设置页新增「报价小宠 · 养成」卡片：显示当前体型/经验/昵称 + 「重置宠物养成」按钮，**确认弹窗**后生效；取消不生效。
- `WB.pet.resetGrowth()`：经验 / 体型 / 昵称归零回幼体；**明确保留位置记忆与已选动物**，不影响任何报价数据。
- **连带根因修复**：旧 `syncFromQuotes()` 每次启动都按历史报价 `amount` 求和并取 `max` 回填经验 ——
  会导致"重置后一刷新就被顶回大橘"。改为**只迁移一次**（`data.synced` 标记），此后由 `onQuote()` 逐单累加驱动成长。

### B5 商务参数小摘要精简

`applyBizCollapsed()` 中「MOQ 5,000 · 不含税 · 税率 13% · 利润率 30%」整行摘要**移除**（`#bizHint` 置空）。
理由：这些数字右侧核算面板已完整、实时呈现，重复展示只增噪点；标题 + 折叠箭头 + 重置按钮已足够表达。
