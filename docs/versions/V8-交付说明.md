## 一、本轮六项需求落地

### ① 工艺复杂度 → 「人工方式」（P1）

**背景缺陷**：`工艺复杂度` 下拉的档位文案随剂型档位名变化（普通/复杂/加难/定制），口径不统一、难培训。

**改动**（`src/index.html` + `src/ui-common.js` + `src/ui-calc.js`）：
- 下拉固定为全局三档 **人工 / 半自动 / 全自动**，不再随剂型变化；旧 OPTION 全部移除。
- 兼容函数 `U.procIdx()/U.procLabel()` + 常量 `PROC_LABELS=['人工','半自动','全自动']`、`PROC_IDX`：历史数据旧档名自动归一——普通→人工(0)、复杂/加难→半自动(1)、定制→全自动(2)；费率取 `processFeeOf(剂型, 档位序号)` 第 0/1/2 档，剂型档位不足三级时回退末档费率 → **旧数据切过来数字与旧版完全一致**（验收用虚构剂型费率 [1.23,2.34,3.45,4.56] 四档对照验证）。
- 切换即 300ms 防抖实时联动重算 + `flashChanged` 高亮，结果区「加工费（人工）」文案同步显示新档名。

### ② 报价小宠：三系 × 三阶图鉴养成（P0）

**重做内容**（`src/ui-pet.js` 51 KB，多精灵养成）：
- **3 只初始精灵、各 3 阶进化链 = 9 形态**，全部纯内联 SVG（每形态独立造型，验收断言 9 组唯一形态）+ CSS 动效，零 emoji / 零外链：
  - 小焰龙（火）：火苗崽 → 焰角龙 → 焚天龙
  - 小电鼠（电）：电豆鼠 → 电气鼠 → 雷神鼠
  - 小天龙（空）：云朵龙 → 飞空龙 → 苍穹龙
- **每只独立经验**（`WB_PET_V2` 分键存储 + V1 镜像兼容迁移），等级阈值 0/10/30/80；Lv4 = 最终体 · 闪耀：金色光环 `.pet-glow` + 光晕 `.pet-shine` + 专属粒子（6×`.pet-amb .pa` + 4×`.pet-dot`）+ 全屏「闪耀」提示。
- **顺序解锁 + 图鉴切换**：小焰龙累计报 10 单 → 解锁小电鼠；伙伴总经验达 20 → 解锁小天龙；解锁后 `setSpecies()` 自由切换，面板/气泡/命名随精灵切换。
- **保留 V7 全部交互**：报价成功跳跃 + 连报兴奋、气泡台词、心情（含 sleep 打盹）、喂糖彩蛋、命名、信息面板开合、双击最小化、**拖动换位且位置持久化（绝不跟随鼠标）**。
- **自动自检**：每 3–5 分钟 `selfCheck()` 巡检并气泡汇报，日志封顶 4 条。
- **API 契约**（V2 起所有迭代保留）：`listSpecies/getUnlocked/getSpecies/setSpecies/unlockSpecies/debugSetCount/getCount/getLevel/getStage/stageOf/svgSpecies/getLogs/selfCheck`；DOM `petRoot/petBubble/petBody/petPanelX/…` 与既有 WB pet 接口兼容。

### ③ 品牌区层级（P1）

- 侧边栏品牌区仅保留 **40px 内联 SVG 图标 + CostDesk（约 17px / 800 深色）+ 单行副标**「成本台 · 采购快速报价」（11px 中灰），垂直居中，无多行堆叠文字。
- 面包屑常驻 `CostDesk · ` 前缀；标题栏/LOGO title 口径一致；全页旧品牌名扫描为 0。

### ④ 消除空缺感（P1）

- **必填标签/占位全量**：`f-name/f-customer/f-weight/f-count/f-net/f-box/f-moq/f-factoryMoq/f-ladder/f-tax/f-profit/f-admin/f-premium/f-testFee/f-freight/f-misc/f-processLevel` 等字段扫描断言，除下拉/有值数字字段外全部给出真实占位或可见默认值。
- **双栏对齐**：产品参数卡 / 商务参数卡统一 `.calc-grid-2`（auto-fill minmax 230px），同栏行高一致。
- **顶部摘要条**：超长文本 CSS 省略号截断 + `title` tooltip 携带完整内容（信息不丢），标题子元素与 tooltip 文案一致。
- **空值显示破折号**：原料/包材明细、快照、报价记录、导出明细等无值单元格统一渲染 `—`（供应商、报价日、成本、客户等缺省项不再空白）；清空方案后空态四入口 `#calcEmpty` 重新出现、摘要条显示「未命名方案」，杜绝「有标题无内容」的空白缺口。

### ⑤ 结果区重排（P0）

**背景缺陷**：旧布局横幅/按钮/卡片混排、按钮文字被截断、层级不清。

**新固定层级**（`src/ui-calc.js` 渲染 `#resultBody`）：
1. 风险横幅独立置顶（黄/红 `.bn-warn/.bn-err`，可展开明细，不中断核算，不与数据混排）
2. **2×2 核心指标卡** `.r-big`：单份成本 / 不含税出厂价 / 含税出厂价（税率%）/ 实际利润率，`data-k="unitCost|upTax|inTax|profitRate"`
3. **饼图 + 占比明细**（扇区 data-k + 图例逐项，中心显示整单总成本）
4. **成本构成明细逐项**（原料含损耗 / 包材 / 加工费（人工方式）/ 管理费 / 检测 / 运费 / 杂费）
5. **整单成本蓝色高亮条** `.total-bar`：`.tb-v` 千分位 ¥
6. **MOQ 阶梯表** `.ladder-table`：新增「整单金额」列，`min-width` 横向滚动不挤压
7. **底部操作**：导出报价单 / 导出 Excel / 存档（按钮文字完整不截断，替换旧 emoji 图标按钮）
- 数字右对齐 + 全千分位；报价完成（已核算）后按 1→7 顺序点亮。
