- 一键归一化沿用，仅文案同步。

## 三、原料自动分类

- 新增规则引擎 `WB.smart.classifyName()`：最长关键词优先、等长时自定义规则优先、大小写不敏感；
- 内置约 110 条关键词映射（维生素/矿物质/氨基酸/草本提取物/益生菌/油脂/糖类/其他 8 大类）；
- 自动分类覆盖**所有写原料入口**：价格库新增/编辑原料（输入即建议，新建自动回填 +「自动识别：X」高亮；编辑态给「采用」按钮不强制；手动改选后不再覆盖）、批量 CSV 导入、粘贴解析入库、识别草稿「建草稿」；
- 识别不到默认归「其他」；已存档数据不强制重分类；
- **设置页规则库可维护**：查看全部规则 / 新增规则（关键词 + 分类，分类支持输入自定义新分类）/ 删除 / 恢复内置默认 / 保存生效；自定义分类自动出现在所有分类下拉中。

### 规则库维护方法
1. 顶部导航 →「设置」→「原料自动分类规则」卡片；
2. 「添加规则」→ 填关键词（如 `胶原蛋白肽`）与分类（可输入新分类如 `蛋白质`）→「保存规则」即时生效；
3. 「恢复默认规则」→ 显示内置规则，点「保存规则」后生效；
4. 规则随主数据存档（localStorage）持久化，JSON 备份/恢复同步携带。

## 四、识别能力加强（本地鲁棒解析 + 可选 AI）

### 本地解析（默认离线，重写引擎 `parseQuoteLines`）
一个入口吃下所有格式，已验证 9 类：

1. **表格粘贴**：Tab/多空格分隔、序号列、表头行、日期列自动跳过；
2. **价格在前**：`85.5 元/kg 维生素C`；
3. **竖排**：名称行 + 价格行上下两行；
4. **千分位/税点/交期噪声剥离**：`1,250.00 元/kg 含税13% 交期15天` → 1250 + 交期15天；
5. **元/克** ×1000、**元/吨** ÷1000 自动换算为元/kg 口径（有换算提示）；
6. **范围价取均值**：`88~92 元/kg` → 90；
7. **外币**：USD/EUR/GBP/HKD/JPY + 符号识别，附汇率换算提示（**入库按原币，不擅自改价**）；
8. **MOQ/日期等噪声剥离**并捕获 MOQ、交期；
9. 名称内数字防误切（辅酶Q10 / DHA30 / B12）、行号清理。

解析结果进**勾选式可编辑预览表**（名称/单价/币种/MOQ 可改、逐行勾选）→ 确认批量入库，分类自动识别。

### AI 增强（可选，纯增强不依赖）
- 设置页「AI 识别增强」卡片：开关 + Endpoint + API Key + 模型名；
- 兼容 OpenAI Chat Completions 接口（如 `https://api.openai.com/v1/chat/completions`，模型如 `gpt-4o-mini`）；OCR 文本与报价单粘贴文本先送 AI 结构化（JSON，附置信度），结果仅作为**建议回填**进预览表，入库前仍需人工勾选确认；
- **未配置/无网/请求失败自动回退本地解析，不崩溃、不阻塞**；未配置时零网络请求（离线纯本地）。

### AI 配置方法
1. 设置 →「AI 识别增强」→ 开关选「开启」；
2. Endpoint 填兼容接口地址、API Key 填密钥（仅存本机浏览器）、模型名如 `gpt-4o-mini`；
3. 「保存设置」后即刻生效；关闭开关即回到纯本地解析。

四个识别入口（图片 OCR / 手动粘贴 OCR 降级 / 文字识别 / 文本配方上传）共用同一套能力。
