# CostDesk 成本台 · 源码包（V14）

保健品 OEM 采购快速报价工作台，单文件离线 HTML 的**模块化源码**。
本包是 V14 质量升级（桌宠深度重绘 + 5 条实测体验优化）后的完整源代码。

---

## 一、这个包是什么

不是"能跑的最小 demo"，而是**可复现的完整工程**：模块化源码 + 构建脚本 + 821 项回归测试 + 桌宠渲染验收管线 + 全部历史交付说明。

- **成品**：`CostDesk.html`（单文件 · 555.0 KB · 双击即用 · 零外链）
- **源码**：`src/` 下 14 个源文件（1 个 HTML 骨架 + 1 个 CSS + 12 个 JS 模块）
- **构建**：`src/build.js` 把源码确定性合并为那一个 HTML
- **测试**：11 套 jsdom 测试，全量 **821 项**
- **验收图**：`验收图/` 下 8 张桌宠 PNG（由 SVG 源码直出）

## 二、上手：30 秒跑起来

### 只想用 → 双击
直接双击 `CostDesk.html`，浏览器打开即用，不需要装任何东西。

### 想改代码 → 构建
需要一个 Node.js（本包在 v22 上验证通过）：

```bash

```

## 四、模块职责与依赖关系

构建顺序即依赖顺序（`build.js` 的 `JS_ORDER`），下层不依赖上层：

```
calc.js        纯计算，无 DOM 依赖
parse.js       纯解析，无 DOM 依赖
classify.js    分类规则 + AI 桥（可 fetch，也可完全离线）
    ↓
store.js       数据层（唯一持有 localStorage 的地方）
    ↓
ui-common.js   通用 UI 原语（toast / confirmDlg / modal）
    ↓
ui-recognize.js / ui-calc.js / ui-libs.js / ui-quotes.js / ui-pet.js
               五个业务视图，各自 export 到 WB.* 命名空间
    ↓
app.js         装配层：init 各视图、view 切换、reloadAll
```

**模块间只通过 `global.WB` 命名空间通信**，不互相 require。这是为了最终能合并成单文件。

## 五、关键约定（改代码前必读）

### 1. 单文件约束
- 源码里**不能出现 `</script>` 字面量**（会破坏内联结构），`build.js` 会直接抛错拦截。
- 成品**零外链资源**：字体、图标、样式、脚本全内联，断网可用。
- 不能把代码拆成多个 `<script src>`，除非同时改构建逻辑。

### 2. HTML 占位符
`index.html` 里只有两个注入点：
```html
<style>/*__CSS__*/</style>
...
<script>
/*__JS__*/
</script>
```
`build.js` 用 `.replace(..., () => ...)` 的函数形式替换（避免 `$&` 等特殊字符被误解析）。

### 3. 测试跑的是构建产物
`test-*.js` 都是读上一级的 `CostDesk.html` 用 jsdom 加载。
**改源码不 build，测试跑的还是旧代码** —— 这是本项目最容易踩的坑。

### 4. jsdom 环境
- `NODE_PATH` 在 Windows 下必须用**正斜杠**，反斜杠转义形式会解析失败。
- 诊断脚本末尾务必 `process.exit(0)`，否则 jsdom 的 timer 会让事件循环不退出、进程挂死。

### 5. 桌宠不能砍功能（历史硬约束）
重绘时只换皮，以下必须保留：
- 6 种情绪：`idle / happy / curious / sleep / excited / upset`
- 3 种体型：幼猫 / 成猫 / 大橘
- 全部动作：`act-jump / act-spin / act-wave / act-chew / act-nuzzle`
- 养成数据：`exp / streak / feeds / name / mood / logs / pos / active / unlocked`

### 6. 宠物经验同步只做一次
`ui-pet.js` 的 `syncFromQuotes()` 有 `data.synced` 一次性迁移标记。
**不要改回"每次启动按历史报价求和"** —— 那会导致「重置养成后一刷新又被顶回大橘」的 bug（V14 修过）。

### 7. AI 是可选增强，不是必需
判据始终是 `if (sm.aiConfig())`（需 aiEnabled + aiEndpoint + aiKey 全齐）。
未配置时必须走本地解析，且**保持同步执行** —— jsdom 里的同步断言依赖这一点。

### 8. 校验错误要能定位
`ui-calc.js` 的 `ERR_FIELD_MAP` + `resolveErrTarget()` 负责把错误文案反查成 DOM 选择器。
新增带必填的剂型字段时，记得让错误文案格式保持 `剂型字段「XXX」为必填`，正则才能命中。

## 八、复现构建（校验一致性）

```bash
cd src && node build.js
```

预期输出：
```
built: ...\CostDesk.html 555.0 KB
bundle js length: 389478
```

产物 sha1（V14 基线）：
```
9981aab6416078b7d0ae051d0eebe3f0750b3ad3
```

`build.js` 的合并是确定性的（固定顺序 + 固定分隔符），同样源码重复构建**字节级一致**。
如果你构建出的 sha1 与之不同，说明源码被改动过。

## 十、已知项（不是 bug）

- `huge.png` 在 1800px 超大倍率下投影边缘有极低透明度模糊的栅格化伪影，属 `resvg` 渲染器的栅格化现象；真实容器尺寸（`clip-check.png`，150×170）完全干净。已给三个 filter 补 `color-interpolation-filters="sRGB"` 降低出现概率。
- V12/V13 的部分旧 SVG 结构断言在 V14 桌宠重绘后已按新结构**重写**（`cdHeadG`/`cdBodyClip`/`mask#cdTailMask` 等），这是契约同步，不是删断言凑绿。
